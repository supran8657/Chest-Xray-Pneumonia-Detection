# Chest-Xray-Pneumonia-Detection
Chest X-ray Pneumonia Detection using Transfer Learning with ResNet50. Built with PyTorch, this project classifies chest X-ray images into Normal and Pneumonia using a pretrained ResNet50 model. 
## Features
- Transfer Learning
- Feature Extraction
- ResNet50
- PyTorch
- Confusion Matrix
- Precision, Recall and F1-score
- Sample Predictions
## Dataset:
Chest X-ray Images (Pneumonia)
https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia
